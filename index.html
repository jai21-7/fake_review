Phone reputation API

Score a number before you trust the call.

Linewise returns a spam-risk score, a line type, and a short recommendation for one phone number. This GitHub Pages site is the documentation. The box below answers immediately, with no API key, because the preview runs in your browser.

Sandbox

No key. No upload. Sample scores are fixed; other numbers are format-checked only.

HTTP 200 


      

    


    

      
Request

      
One lookup, one number. Send the number in E.164: a plus sign, a country calling code, and the rest of the digits. The sandbox accepts spaces, dashes, and a bare 10-digit US number. The hosted API asks for the plus form.

Response schema

      
A 200 body always has the same keys. On a sample number the reputation fields are filled. On any other number reputation.risk_score is null and live_lookup stays false.

What a client should do at the limit

      
    
        
  • Stop when the response status is 429.
    • 
        
  • Wait the number of seconds in the Retry-After header, then try once.
    • 
        
  • Read X-RateLimit-Limit, X-RateLimit-Remaining, and X-RateLimit-Reset (Unix time, UTC) before you fan out a batch.
    • 
        
  • Do not retry a 400. The number will not become valid by asking again.

Freshness, privacy, and what this page will not do

      

        

          
Freshness

          
Sample scores on this page were set on the date in freshness.reputation_as_of. They do not move when you reload.

          
The contract for a hosted deployment is stricter than a demo: a reputation record should be refreshed at least every 24 hours, and freshness.max_age_hours tells the client when to stop trusting a cached block. Number-class facts, such as “1-900 is premium-rate”, come from the numbering plan and change rarely. Report counts are aggregates, not a recording of a call.

        

        

          
Privacy

          
A number typed into the sandbox stays in the page. The script does not call fetch. Check the network panel if you want to see that for yourself.

          
The response has no subscriber name, street address, contacts, or map location. Those fields are omitted because a spam-risk check does not need them. Use the score to allow, challenge, or block a call inside your own app. Do not use it to identify or harass a person.

          
There is no production lookup service in this repository. api.example.com is documentation, not a live host. Phone numbers are personal data under laws such as the GDPR when they can be tied to a person; a hosted version of this API would need its own notice, a short retention window for request logs, and a reason for processing that is limited to fraud and spam prevention.
